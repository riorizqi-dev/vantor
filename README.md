# VANTOR — Luxury Watch Brand Landing Page

Premium, cinematic landing page for **VANTOR**, a luxury watch brand born from the idea of valor — courage, confidence, and timeless masculinity.

## Highlights

- Cinematic hero with mouse-reactive particles & magnetic CTAs
- Scroll-driven storytelling (GSAP ScrollTrigger + Lenis smooth scroll)
- Reveal-on-scroll sections: About, Features, Audience, Products, Marquee
- Tilt cards, counter animations, custom mouse follower, film grain overlay
- Fully responsive, reduced-motion aware

## Stack

- Next.js 15 (App Router), React 19, TypeScript
- Tailwind CSS 4
- Framer Motion, GSAP ScrollTrigger
- Lenis, Swiper, Lucide icons

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```
